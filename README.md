# Japan Through Bathing Culture

Public-facing website for an independent documentary project exploring Japanese bathing culture through people, places, craft, history and everyday life.

## v0.1

- Static HTML / CSS / JavaScript — no build step.
- Responsive layout.
- Accessibility-minded semantic structure, keyboard focus states and reduced-motion support.
- English, French and Japanese.
- Initial language selection:
  1. `?lang=en|fr|ja`
  2. saved visitor preference
  3. browser language
  4. English fallback
- Manual language switcher persists the visitor's choice.
- First visual direction uses CSS/SVG rather than stock photography.

## GitHub Pages

In the repository:

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**.
4. Save.

Expected Pages URL:

`https://arnaudsyn.github.io/Bath-doc/`

Useful language links:

- English: `https://arnaudsyn.github.io/Bath-doc/?lang=en`
- Français: `https://arnaudsyn.github.io/Bath-doc/?lang=fr`
- 日本語: `https://arnaudsyn.github.io/Bath-doc/?lang=ja`
